# מפת הפשיעה בישראל

מערכת פנימית לחקירת נתוני הפשיעה של משטרת ישראל (קובץ CSV קבוע, 2025) על מפה תלת־ממדית אינטראקטיבית.
React + Node.js (Express), ללא מסד נתונים, ללא מפתחות API וללא שירותים בתשלום.

## הרצה

```bash
npm install
npm run dev        # פיתוח – שרת אחד (API + Vite) בכתובת http://localhost:5173
# או:
npm run build && npm start   # גרסת production מתוך dist/
```

פורט חלופי: `PORT=8080 npm start`. השרת מאזין ל-127.0.0.1 בלבד (שימוש פנימי).
נדרש חיבור אינטרנט עבור אריחי מפת הבסיס (OpenFreeMap) והפונטים.

## מבנה

| נתיב | תוכן |
| --- | --- |
| `data.csv` | קובץ המקור (Windows-1255, קריאה בלבד) |
| `server/data.js` | טעינה, אימות כותרות, סינון וקיבוץ בזיכרון, ייצוא CSV |
| `server/geo.js` | שיוך גיאוגרפי לפי קודים בלבד (`YeshuvKod`, `StatisticAreaKod`) |
| `server/index.js` | REST API (`/api/health`, `metadata`, `localities`, `summary`, `map`, `areas/:code`, `records`, `export`) |
| `server/geo/*.geojson` | גבולות למ"ס (נוצרים ע"י `npm run fetch-geo`) |
| `src/MapView.jsx` | MapLibre GL – מפת חום (Choropleth), בחירה, ריחוף, 2D/3D |
| `src/LifeLayer.js` | שכבת three.js – הולכי רגל, רכבים ורמזורים ברמת רחוב (קישוט בלבד) |
| `src/Panels.jsx`, `src/DetailView.jsx` | פילטרים, מקרא, תקציר, תצוגה מורחבת, טבלאות וייצוא |

## מקורות גיאוגרפיים וכיסוי בפועל

- מפת בסיס: OpenFreeMap / OpenMapTiles / OpenStreetMap (מבנים בתלת־ממד לפי גבהי OSM).
- גבולות: הלמ"ס – אזורים סטטיסטיים 2011 ו-2022 ונקודות יישובים (שירותי ArcGIS ציבוריים).
- יישובים: 222 מתוך 223 קודי היישובים ממופים (חסר: 3826 "שער שומרון").
- אזורים סטטיסטיים: 1,549 מתוך 1,561 ממופים (1,499 לפי חלוקת 2011, 50 לפי התאמת קוד לחלוקת 2022 – מסומן בפאנל). 12 אזורים ללא גיאומטריה.
- רשומות ללא יישוב (1,824) או ללא אזור (4,938) אינן מוצגות על המפה, אך נספרות ונגישות בטבלאות, במדד "רשומות ללא מיפוי" ובייצוא. לא מומצאים מיקומים.

## הערות נתונים

- יחידת הספירה היא רשומה; אין deduplication לפי `FictiveIDNumber`.
- קבוצות `-1` ("שגיאת הזנה") ו-`1300` ("סעיפי הגדרה") מסומנות כ"סיווג טכני" ונשארות בספירה.
- סולם הצבעים הוא שורש (√) של כמות הרשומות ביחס למקסימום באותה רמה (יישובים / אזורים), תחת הסינון הפעיל.
- שכבת "רחוב חי" (אנשים, רכבים, רמזורים) היא הדמיה חזותית של רקע גיאוגרפי בלבד ואינה מייצגת נתוני פשיעה. רמזורים נטענים מ-OSM (Overpass); כשהשירות אינו זמין הם מוצבים בצמתים ראשיים ומסומנים כך בממשק.
